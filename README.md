# andreev.uz

Главная страница andreev.uz.

- Хостинг: Cloudflare Workers (static assets), Worker `andreev`
- Деплой: автоматически при пуше в `main`
- Домен: andreev.uz (www → редирект на корень)

## Проекты

- `/eddie/` — книжный спецпроект VSplanet «Обмани смерть. Укради жизнь» (статический PWA-сайт). Исходники стилей и скриптов: `eddie/style.css`, `eddie/app.js`; после правок выполните `prepare-release.py` из архива проекта и скопируйте `dist/` сюда.
