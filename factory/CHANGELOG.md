# VSplanet Книги: версии

Каждая версия получает номер (и при желании название). Номер виден внизу полки и каждой книги, а в Git стоит тег `vX.Y`.

## 1.15 — 1 ноября 2026
- Исправлено скачивание книг: Cloudflare перенаправляет адреса *.html, а скачивание отвергает перенаправления. Главы теперь лежат в файлах .txt. Так же быстрее открываются главы в читалке (нет лишнего перехода).

## 1.14 — 1 ноября 2026
- Скорость: книга грузится по главам. Страница книги весила 2,5 МБ, теперь 0,36 МБ; поиск подгружает весь текст только при первом запросе. Следующая глава подгружается заранее.
- Шрифты Literata облегчены вдвое (348 → 162 КБ): оставлен один оптический размер и нужные символы.
- Кэш: файлы с хэшем в имени (стили, скрипты, главы, индекс книги) кэшируются браузером навсегда (`_headers`).
- Убраны пустоты под подвалом на полке и в «В работе» (двойной отступ под панелью вкладок).
- Удалён мёртвый код: блок «Эпохи» (данные сохранены), индикатор вкладок, ~1,5 КБ неиспользуемых стилей.
- Исправлено «Письмо переводчика» у книги Эдди: маркер не находился из-за неразрывного пробела.
