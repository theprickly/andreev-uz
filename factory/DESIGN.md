# Дизайн-система «VSplanet Книги»

Один набор токенов на полку, страницы книг и читалку. Токены лежат в `template/nav.css` (блок `:root` в начале), общие для всех страниц.

## Цвета
| Токен | Значение | Где |
|---|---|---|
| `--navy` | `#052464` | основа логотипа: глубокие поверхности, блок «Помогите дописать», свечение фона |
| `--sky` | `#68a0d9` | основа логотипа: ссылки, имена авторов, контуры, вторичные акценты |
| `--sky-hi` | `#9cc2ea` | наведение, светлые подписи |
| `--a1` `--a2` `--a3` | `#f19454` · `#e43764` · `#311466` | акцентный градиент: оранжевый → розовый → фиолетовый |
| `--grad` | `linear-gradient(100deg, a1, a2 50%, a3)` | главные кнопки, активная вкладка, кнопка установки, шкалы прогресса, кавычка цитаты |
| фон | `#03060c`, поверхности `rgba(255,255,255,.055 / .09)` | |

Правило: градиент — только для главного действия на экране и состояния «сейчас здесь». Всё остальное — navy, sky и нейтральные.
Цвет обложки интерфейс не красит.

## Логотип
- Знак (щит с буквами VS): `template/assets/vsplanet-mark.svg`. Рисуется градиентами (лёд `#A2DCFF → #4699D5 → #266AA6`, щит `#143D7A → #052464 → #031535`), рассчитан на тёмный фон.
- Горизонтальный логотип (знак + слово VSPLANET, Geologica Bold, белое): `template/assets/vsplanet-lockup.svg`. Используется в верхней панели полки и в шапках книг, после него подпись «Книги».
- Иконки приложения, превью ссылок и обложки-заглушки собираются из знака автоматически.
- Охранное поле — не меньше половины высоты знака. Знак градиентом акцента не красится.

## Материалы (iOS 27, Liquid Glass)
- Стекло (`.glass`, нижняя панель, верхняя панель, шапка читалки): размытие 26px, насыщенность 1.9, тонкая светлая кромка сверху, тёмная — снизу. Без внешних «тяжёлых» теней.
- Системные настройки уважаются: «Уменьшить прозрачность» делает стекло сплошным, «Повышенная контрастность» усиливает кромки.
- Карточки, группы — полупрозрачная заливка `--s1` с внутренней обводкой.

## Типографика
- Заголовки и интерфейс: Geologica. Текст книг: Literata.
- Большой заголовок: 34–54 px, вес 800, трекинг −0.04em; сворачивается в 16 px в верхней панели.

## Формы и отступы
- Радиусы: кнопка и сегмент — капсула, карточка 24 px, крупный блок 30 px.
- Тач-цель — не меньше 44 px. Поля ввода — 16 px.
- Пружинная кривая: `cubic-bezier(.3,1.35,.5,1)`; плавная: `cubic-bezier(.32,.72,0,1)`.

## Компоненты
Кнопка (`.btn`, `.btn.big`), сегмент (`.seg`), карточка книги, «Продолжить чтение», блок помощи, эпохи, карусель цитат, нижняя панель (сжимается при прокрутке), верхняя панель (большой заголовок → маленький), шторки, плашка «Вышла новая версия».

## Шрифты
Интерфейс и заголовки: **Geologica** (800 для больших заголовков, 500–700 для остального). Текст книг: **Literata**. Оба — OFL, лежат на сайте и работают без сети.

## Где что лежит
Токены: `template/nav.css` (начало). Стили полки: `shelf.css`. Читалка: `style.css`. Тема книг: `scripts/themes.py` (единая). Сборка: `scripts/build_all.py`. Версия: `VERSION.json` и `CHANGELOG.md`.
