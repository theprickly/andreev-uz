# VSplanet · Книжная фабрика

Конвейер переноса книг-переводов с vsplanet.net в формат «VSplanet Книги»: читалка с прогрессом и закладками, EPUB, страницы глав для поисковиков.

## 1. Сбор (GitHub Actions, ветка `book-factory`)
У vsplanet.net закрыт доступ из рабочей среды, поэтому скачивание идёт на серверах GitHub.
Положите JSON в `factory/requests/` и запушьте в `book-factory` — workflow сохранит результат в `factory/out/<имя>/`.
- `{"type":"discover"}` — найти книжные серии (заголовки «… Глава N»).
- `{"type":"fetch","search":"Неоспоримый","title_regex":"Джерико.{0,4}Неоспоримый"}` — скачать посты и картинки серии.

## 2. Нормализация — `scripts/normalize.py`
Посты → `books/<slug>/book.json`: номера глав в любом виде (Глава 1 / глава 10 / #17 / II / 1.1 / (ч. 2)), склейка частей, названия глав из оригинала, предисловия и благодарности по дате, чистка разметки WordPress, видео → «Из архива VSplanet», «прим. пер./ред.» → сноски, курсивные комментарии редакции → «Примечание редакции», подписи переводчиков → `book.credits`, битые картинки (мёртвые фотохостинги) выбрасываются и считаются.

## 3. Проверка качества — `scripts/qa.py`
Отчёт `qa.md` с оценкой 0–100: пропуски и дубли глав, типографика, следы веб-публикации, разнобой имён, орфография (Hunspell), кальки, канцелярит, непереведённые куски. `--fix` правит только безопасное (тире, многоточия, пробелы).

## 4. Адаптация — `books/<slug>/book.config.json`
Метаданные, текст главной, выходные данные, страница «О сайте» и `replacements` — согласованные написания имён по итогам qa.md. Лог применения — `adaptation.log`.

## 5. Сборка — `scripts/cover.py` + `scripts/build_book.py`
Серийная обложка и 3D-рендер (или `cover_image` с готовой обложкой), сайт из `template/`, EPUB 3 (проверка EPUBCheck), значки, превью для соцсетей, `chapters/*.html` и `sitemap.xml`.

Всё вместе: `factory/run.sh <out> <slug> "<Название>"` → готовая папка `/<slug>/` в корне сайта.
