# vsplanet.net/books/ — инструкция по заливке

Это **статический раздел**: только HTML, CSS, JS, картинки и шрифты. Ни PHP, ни базы данных.
WordPress и остальной vsplanet.net **не затрагиваются**: достаточно положить папку `books` рядом с файлами сайта.

## Что нужно сделать (≈10 минут)

1. **Папка.** Распаковать архив `books-vsplanet-books.zip`. Внутри — папка `books/`.
   Залить её в корень сайта vsplanet.net так, чтобы получилось `<корень сайта>/books/index.html`
   (рядом с `wp-config.php`, но не внутри `wp-content`). Скрытый файл `books/.htaccess` залить обязательно.
2. **Свободен ли адрес.** В WordPress не должно быть страницы, рубрики или записи с адресом `/books/`
   (Страницы → поиск «books»; Настройки → Постоянные ссылки). Если есть — сообщите владельцу, адрес нужно освободить.
3. **Сервер.**
   - **Apache** — ничего настраивать не нужно, все правила в `books/.htaccess`
     (нужны модули mod_rewrite и mod_headers; обычно включены). Проверьте, что для папки разрешён `AllowOverride All`.
   - **nginx** — готовый блок `nginx-books-path.conf`: вставить в `server { }` сайта vsplanet.net, перезагрузить nginx.
4. **Кэш и защита.** Если стоит плагин кэша (WP Rocket, LiteSpeed, W3 Total Cache), Cloudflare или плагин безопасности:
   - исключить из кэша и оптимизации (минификации, отложенной загрузки JS) адрес `/books/*`;
   - не добавлять к ответам `/books/*` свои заголовки CSP — в разделе они уже заданы и разрешают только свой домен и счётчик Яндекс Метрики (`mc.yandex.ru`).
5. **robots.txt.** В **корневой** `https://vsplanet.net/robots.txt` (не в папке books) добавить строку:
   `Sitemap: https://vsplanet.net/books/sitemap.xml`
   Если robots.txt генерирует SEO-плагин (Yoast, Rank Math), добавьте строку через его настройки.
6. **Service worker.** У раздела свой `books/sw.js` с областью `/books/`. Если на основном сайте есть свой service worker (PWA-плагин), убедитесь, что он не перехватывает `/books/*`.

## Проверка после заливки

- https://vsplanet.net/books/ — полка с книгами;
- https://vsplanet.net/books/eddie/chapters/01.html — глава;
- https://vsplanet.net/books/nope — страница 404 в стиле раздела (не страница WordPress);
- https://vsplanet.net/books/eddie/index.html перенаправляет на `/books/eddie/` (301);
- https://vsplanet.net/books/sitemap.xml и https://vsplanet.net/robots.txt открываются;
- в ответе страницы есть `content-encoding: gzip` (или `br`) и заголовок `content-security-policy`.

## Объём

~970 файлов, ~43 МБ. Нагрузка минимальная: страницы статичные и кэшируются браузером.

## Обновления

Новые версии приходят таким же архивом. **Заменять папку `books/` целиком**, а не отдельные файлы:
файлы с хэшем в имени кэшируются на год. Откат — залить предыдущий архив.

## После запуска: поисковики (делает владелец сайта)

- Если vsplanet.net уже подтверждён в Google Search Console и Яндекс Вебмастере, раздел `/books/` виден там автоматически.
  Достаточно добавить карту сайта `https://vsplanet.net/books/sitemap.xml` в оба сервиса.
- Файлы подтверждения прав на сайт не удалять.
