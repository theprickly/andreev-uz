# books.vsplanet.net — инструкция по заливке

Это **статический сайт**: только HTML, CSS, JS, картинки и шрифты.
Нет PHP, нет базы данных, WordPress и основной сайт vsplanet.net **никак не затрагиваются**.

## Что нужно сделать (≈15 минут)

1. **DNS.** Добавить запись для поддомена `books` — A-запись на IP сервера
   (тот же, что у vsplanet.net) или CNAME `books → vsplanet.net`.
2. **Папка.** Создать отдельный виртуальный хост / поддомен `books.vsplanet.net`
   со своей корневой папкой (например, `/var/www/books.vsplanet.net`).
   Не внутри папки WordPress.
3. **Файлы.** Залить в эту папку **всё содержимое папки `site/`**
   (включая скрытый файл `.htaccess`). Внутри должно лежать `index.html` прямо в корне.
4. **HTTPS.** Выпустить сертификат на `books.vsplanet.net` (Let's Encrypt / панель хостинга).
   HTTPS обязателен: без него не работает офлайн-режим читалки.
5. **Проверка.** Открыть:
   - https://books.vsplanet.net/ — полка с книгами
   - https://books.vsplanet.net/eddie/chapters/01.html — глава
   - https://books.vsplanet.net/nope — должна быть страница 404

## Сервер

- **Apache** (обычно рядом с WordPress) — ничего настраивать не нужно,
  правила кэширования уже в `site/.htaccess` (нужны модули mod_headers, mod_rewrite — стандартные).
- **nginx** — готовый блок в `nginx-books.conf`, поменять только путь `root`.

## Объём

~920 файлов, ~40 МБ. Нагрузка минимальная: все страницы статичные и кэшируются браузером.

## Обновления

Новые версии приходят таким же архивом. Достаточно заменить содержимое папки целиком.
Откатить — залить предыдущий архив.

## После запуска: поисковики (5 минут, делает владелец сайта)

1. **Google Search Console** → «Добавить ресурс» → тип «Ресурс с префиксом в URL» → `https://books.vsplanet.net/`.
   Если домен vsplanet.net уже подтверждён как «Доменный ресурс», поддомен подтвердится сам.
   Иначе — подтверждение HTML-файлом: положить выданный файл `google….html` в корень сайта.
   Затем «Файлы Sitemap» → добавить `sitemap.xml`.
2. **Яндекс Вебмастер** → «Добавить сайт» → `https://books.vsplanet.net` → подтверждение HTML-файлом в корне
   (или DNS-записью TXT) → «Индексирование → Файлы Sitemap» → `https://books.vsplanet.net/sitemap.xml`.
3. Файлы подтверждения при следующих обновлениях не удалять.

## Проверка после заливки

- `https://books.vsplanet.net/robots.txt` и `/sitemap.xml` открываются;
- `https://books.vsplanet.net/eddie/index.html` перенаправляет на `/eddie/` (301);
- `http://…` перенаправляет на `https://…`;
- в ответе страницы есть заголовок `content-encoding: gzip` (или `br`).
